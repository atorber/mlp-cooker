# 快速开始

本指南将帮助您快速搭建和运行 MLP Cooker 系统。

## 环境要求

- **Node.js** >= 20.0.0
- **npm** >= 8.0.0

## 方式一：Mac 一键安装（推荐）

在 macOS 上可直接使用项目提供的安装脚本：

```bash
curl -fsSL https://raw.githubusercontent.com/atorber/mlp-cooker/main/install-mac.sh | bash
```

若已克隆仓库：

```bash
cd mlp-cooker
./install-mac.sh
```

脚本会完成环境检查、依赖安装并启动后端。更多说明见项目根目录 [INSTALL.md](https://github.com/atorber/mlp-cooker/blob/main/INSTALL.md)。

## 方式二：手动安装

### 1. 克隆项目

```bash
git clone https://github.com/atorber/mlp-cooker.git
cd mlp-cooker
```

### 2. 安装依赖

### 安装后端依赖

```bash
cd backend
npm install
```

### 安装前端依赖

```bash
cd frontend
npm install
```

### 3. 配置系统

项目支持多 AK/SK 配置与隔离，您可以直接修改 `config.yaml` 或通过前端「系统设置」进行管理。

#### 示例配置 (`config.yaml`)

```yaml
# 默认凭证 (Default)
ML_PLATFORM_RESOURCE_AK: your_ak_1
ML_PLATFORM_RESOURCE_SK: your_sk_1
ML_PLATFORM_RESOURCE_BASE_URL: https://aihc.bj.baidubce.com

# 更多登录凭证 (支持多租户隔离)
PLATFORM_CREDENTIALS:
  - name: "项目组A"
    ak: "ak_project_a"
    sk: "sk_project_a"
    baseUrl: "https://aihc.bj.baidubce.com"
  - name: "项目组B"
    ak: "ak_project_b"
    sk: "sk_project_b"
    baseUrl: "https://aihc.su.baidubce.com"

# 资源池与存储配置
ML_PLATFORM_RESOURCE_POOL_ID: your_resource_pool_id
ML_PLATFORM_RESOURCE_QUEUE_ID: your_queue_id
ML_PLATFORM_RESOURCE_PFS_INSTANCE_ID: your_pfs_instance_id
ML_PLATFORM_RESOURCE_BUCKET: your_bucket_name
```

### 4. 认证逻辑

1. **登录方式**：系统使用 Access Key (AK) 和 Secret Key (SK) 进行登录。
2. **多凭证管理**：登录成功后，您可以前往「管理」->「系统设置」查看和维护全量凭证。
3. **隔离机制**：系统会根据当前登录的 AK/SK 自动筛选该凭证下的资源（部署服务、训练任务等），确保多项目间的零干扰。

### 4. 启动应用

### 方式一：分别启动前后端（推荐开发环境）

**终端 1：启动后端服务**

```bash
cd backend
npm run dev
```

后端服务将在 `http://localhost:8001` 启动。

**终端 2：启动前端服务**

```bash
cd frontend
npm run start:dev
```

前端应用将在 `http://localhost:8000` 启动。

### 方式二：生产环境构建

**构建前端**

```bash
cd frontend
npm run build
```

**启动后端（生产模式）**

```bash
cd backend
npm run build
npm run start:prod
```

### 5. 访问应用

### 开发环境
- **前端应用**: http://localhost:8000
- **后端API**: http://localhost:8001

### 登录方式
系统使用 Access Key (AK) 和 Secret Key (SK) 进行登录认证。首次登录后,AK/SK 会自动保存到配置文件中。

## 注意事项

1. **首次使用**：首次登录需要使用有效的 AK/SK,登录成功后会自动保存到配置文件
2. **配置文件**：确保 `config.yaml` 文件存在且配置正确
3. **网络连接**：确保网络连接正常,能够访问 AIHC 平台 API
4. **Node.js 版本**：确保 Node.js 版本 >= 20.0.0
5. **端口占用**：确保后端端口（8001）和前端端口（8000）未被占用
