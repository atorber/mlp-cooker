# 数据集管理

数据集是机器学习的基础。MLP Cooker 提供全面的数据集资产管理能力，涵盖数据存储、版本控制及数据处理。

## 存储类型支持

系统原生支持 AIHC 平台常用的两种存储类型：
- **BOS (Baidu Object Storage)**：适用于大规模海量数据存储，支持通过 lakeFS 进行精确版本管理。
- **PFS (Parallel File System)**：适用于高性能训练场景，提供极低延迟的文件访问。

## 核心操作

### 1. 数据集概览
在「数据集」主列表页，您可以：
- **查看状态**：实时监控数据集的创建与就绪状态。
- **详情查看**：进入详情页查看元数据、存储路径及创建者信息。

### 2. lakeFS 仓库管理 (BOS 专属)

对于 BOS 类型的数据集，MLP Cooker 提供了深度集成的**数据版本化**能力：
- **创建仓库**：在数据集列表的操作列中，选择「创建仓库」。
- **自动配置**：系统会根据数据集名称和 BOS 路径，自动预填仓库 ID、S3 存储命名空间等关键参数。
- **Git-like 体验**：创建成功后，您可以在后台或 lakeFS 控制台中使用分支、提交、合并等操作来管理数据集版本，确保实验的可追溯性。

### 3. 数据处理与导入
- **数据处理**：支持对选定数据集版本下发预处理任务。
- **数据导入**：支持将外部数据按规则导入到当前数据集存储中。

## UI 交互标准

数据集管理遵循全站统一的 **Threshold of 2** 交互规范：
- 如果可见操作较少（如只有「详情」和「删除」），操作列将直接平铺按钮。
- 如果操作项较多（包含「详情」、「版本」、「创建仓库」、「删除」等），则仅平铺「详情」，其余操作全部收纳在「更多 ▼」下拉菜单中，以保持界面整洁稳定。
