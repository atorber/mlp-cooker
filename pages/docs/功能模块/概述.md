# 功能模块

MLP Cooker 提供完整的机器学习平台管理能力，覆盖从配置、资产、执行到工作流的全生命周期。以下对照当前前端菜单与页面结构。

## 菜单结构（与前端一致）

| 菜单 | 路径 | 说明 |
|------|------|------|
| 概览 | `/welcome` | 平台统计与资源概览 |
| 应用 | `/application` | 可执行应用入口，引用模板配置一键发起任务 |
| 工作流 | `/workflow` | 工作流列表与编排 |
| AI资产 | `/ai-assets/*` | 模板、数据集、模型、镜像、任务 |
| 数据仓库 | `/data-warehouse` | LakeFS 仓库与分支管理 |
| 资源 | `/resource/*` | 开发机、部署、训练、队列、资源池、存储 |
| 全局配置 | `/settings/global` | 默认资源池 / 队列 / 存储与平台组件 |
| 系统设置 | `/settings/system` | AK/SK、区域等系统级配置 |

## 核心模块说明

### 1. 概览 (Welcome)

平台统计概览，包括：

- 部署服务、训练任务、批量任务数量
- 数据集、模型数量
- 计算资源使用情况

### 2. 应用 (Application)

面向用户的「快捷启动器」。应用本身不内嵌完整任务参数，而是通过 `actions[].templateId` **引用模板库**中的配置：

- 按分类（模型 / 任务 / 工具）浏览与筛选
- 一键发起：部署推理服务、创建训练任务、创建批量任务
- 支持从已有训练任务导入为应用（自动写入模板并关联）
- 详情可查看关联的模板 ID 与解析后的配置参数

> 应用与模板的关系：应用负责「展示与执行」；模板的 `template_content` 保存 `taskParams` / `command` / `accelerators` 等可执行配置。

### 3. 工作流 (Workflow)

- 工作流列表、创建、更新、删除
- 可视化编排编辑器（`/workflow/editor/:id`）

### 4. AI资产

#### 模板 (Template) (`/ai-assets/template`)

全平台业务模板资产库，支持预置（`preset`）与自定义（`custom`）：

- 字段：`id`、`name`、`logo_type`、`description`、`doc_url`、`source`、`module`、`sub_module`、`tags`、`template_content`、`version`
- 功能模块：通用、资源池、分布式训练、在线服务部署、开发机、工作流
- 子模块与功能模块联动（如工作流 → 工作流模板 / 子任务模板）
- 支持按关键词、模块、标签、来源筛选
- 详情支持 Markdown 文档预览（`doc_url`）
- 自定义模板可增删改；预置模板只读

> 模板菜单已迁至「AI资产」下；旧路径 `/template` 会重定向到 `/ai-assets/template`。

#### 数据集 (Dataset)

- 列表（支持 BOS / PFS 存储类型）
- 详情、版本管理、文件浏览与预览

#### 模型 (Model)

- 列表、详情、版本创建与删除

#### 镜像 (Image)

- 公共镜像 / 自定义镜像
- 版本与状态管理

#### 任务 (Task)

- 批量任务列表（过滤含 `task-` 关键字的 Job）
- 任务详情

### 6. 数据仓库 (Data Warehouse)

基于 LakeFS：

- 仓库列表与创建
- 分支、对象浏览、Diff、Commit

### 7. 资源

#### 开发机 (Dev Machine)

- 开发机列表、创建、停止、删除

#### 部署 (Deployment)

- 服务列表、详情、状态、创建与删除

#### 训练 (Training)

- 训练任务列表、详情、创建、停止、删除
- WebTerminal 等运维能力

#### 队列管理 (Queue)

- 默认队列详情、资源统计、MLP Cooker 组件状态

#### 资源池 (Pool)

- 资源池列表与详情
- 设为默认资源池

#### 存储 (Storage)

- **存储桶文件**：浏览对象存储（BOS）文件
- **PFS 文件**：依赖集群内 `mlp-cooker` 常驻组件挂载 PFS；组件失败时可提示并重启

> 存储菜单已从「AI资产」迁至「资源」下；旧路径 `/ai-assets/storage` 会重定向到 `/resource/storage`。

### 8. 全局配置 (Global Config)

- 默认资源池、默认队列
- 对象存储桶、PFS 实例 ID
- 平台组件（如 mlp-cooker）初始化 / 卸载

### 9. 系统设置 (Settings)

- 机器学习平台 AK/SK、区域、Base URL 等
- 多凭证 / 环境相关配置
