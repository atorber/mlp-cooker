# 应用与模板

应用与模板是两个互补能力：**模板**管理可复用的配置资产，**应用**引用模板并提供一键执行入口。

## 定位对比

| 维度 | 应用 (`/application`) | 模板 (`/template`) |
|------|----------------------|-------------------|
| 目标 | 快捷启动训练 / 部署 / 任务 | 登记与管理业务模板定义 |
| 是否可执行 | ✅ 可直接发起平台任务 | ❌ 不直接创建资源 |
| 配置存放 | 通过 `templateId` 引用 | `template_content` 保存参数 |
| 数据位置 | `backend/data/app/{appId}/app.json` | `backend/data/db/templates.json` |

## 应用如何引用模板

应用 `app.json` 中每个动作通过 `templateId` 关联模板库：

```json
{
  "name": "示例训练应用",
  "description": "从模板加载训练配置",
  "type": "training",
  "categoryType": "model",
  "tags": ["训练", "示例"],
  "actions": [
    {
      "type": "train",
      "label": "创建训练任务",
      "templateKey": "train",
      "templateId": 106
    }
  ]
}
```

后端加载应用时，会按 `templateId` 读取模板的 `template_content`，解析为运行时配置（兼容过渡期本地的 `train.json` 等旧文件）。

### template_content 结构（应用配置）

```json
{
  "taskParams": {
    "jobType": "PyTorchJob",
    "jobSpec": {
      "replicas": 1,
      "image": "registry.example.com/train:latest",
      "resources": [],
      "envs": []
    }
  },
  "command": "python train.py",
  "accelerators": {
    "baidu.com/a800": 8
  }
}
```

## 使用应用

### 浏览与筛选

在「应用」页面：

- 按分类（模型 / 任务 / 工具）筛选
- 按名称、描述搜索
- 卡片展示可用操作按钮（部署、训练、创建任务等）

### 一键执行

点击操作按钮后：

1. 系统根据关联模板填充默认参数
2. 可按需调整环境变量等业务参数
3. 确认后调用对应 API（如 `/api/jobs/create`、`/api/services`）创建资源

### 从训练任务导入

「导入训练任务」会：

1. 读取任务详情中的配置
2. 在模板库创建一条自定义模板（写入 `template_content`）
3. 创建应用目录，并在 `actions` 中写入 `templateId`

## 使用模板库

在「模板」页面：

1. 按功能模块、标签、来源（全部 / 预置 / 自定义）筛选
2. 查看详情：简介、文档链接、模板内容、版本
3. 若 `doc_url` 为 Markdown 内容或 `.md` 文件，详情抽屉会渲染预览
4. 自定义模板支持新增、编辑、删除；预置模板不可修改

### 功能模块与子模块

| 功能模块 | 可选子模块 |
|----------|------------|
| 通用 | （无） |
| 资源池 | 资源套餐模板 |
| 分布式训练 | 任务模板 |
| 在线服务部署 | 服务模版 |
| 开发机 | （无） |
| 工作流 | 工作流模板、子任务模板 |

子模块仅保存 `/` 后的名称（如 `子任务模板`），并与所选功能模块联动。

## 自定义应用（开发）

推荐流程：

1. 在「模板」页先创建/维护配置（或直接在 `templates.json` 写入 `template_content`）
2. 在 `backend/data/app/{appId}/` 创建 `app.json`，`actions` 填写对应 `templateId`
3. 重启或热重载后端后，在「应用」页验证一键执行

更完整的开发约定见：[backend/data/app/README.md](https://github.com/atorber/mlp-cooker/blob/main/backend/data/app/README.md)
