# 应用模板

应用模板是 MLP Cooker 的核心功能之一,提供预定义的应用配置,支持一键部署、训练和任务创建。

## 模板结构

应用模板采用目录结构组织,每个应用包含：

- `app.json`：应用元数据
- `deploy.json`：部署模板
- `train.json`：训练模板
- `create-job.json`：任务创建模板
- `deploy-tool.json`：工具部署模板
- `{action-type}.command.sh`：命令脚本

## 使用应用模板

### 1. 浏览与查询模板

在「应用中心」页面，您可以浏览所有可用的应用模板。为了更快速地找到目标，系统提供了以下增强功能：
- **关键词搜索**：支持按应用名称或描述进行即时搜索。
- **分类标签展示**：每个模板卡片会展示其所属标签（如 `LLM`、`VLM` 等），点击标签可快速筛选同类应用。
- **多功能过滤**：侧边栏支持按业务分类、应用场景等多个维度进行复合筛选。

### 2. 环境管理 (灰度与生产)

MLP Cooker 支持应用模板的灰度发布机制：
- **环境切换**：页面右上角提供「灰度环境」与「生产环境」切换开关。
- **配置隔离**：不同环境对应不同的后端服务地址，确保在正式发布到生产环境前，可以在灰度环境进行充分调试。
- **发布状态**：应用卡片会标记 `NEW` 或 `HOT` 等状态，方便识别最新或热门的应用。

### 3. 查看与部署

点击应用卡片可以进入详情页，查看其详细元数据、参数结构及使用说明。
选择相应的操作按钮（部署/训练/创建任务），系统会自动弹出配置表单并由模板自动填充默认参数。您只需：
1. 根据实际需求微调核心参数（如实例规格、镜像版本等）。
2. 点击确认，系统将通过 API 下发任务到 AIHC 平台。

## 自定义模板

### 创建新模板

1. 在 `backend/data/app/` 目录下创建应用目录
2. 创建 `app.json` 定义应用元数据
3. 创建操作模板文件（`deploy.json`、`train.json` 等）
4. 创建命令脚本文件（`{action-type}.command.sh`）

### app.json 示例

```json
{
  "id": "my-app",
  "name": "我的应用",
  "description": "应用描述",
  "category": "推理",
  "tags": ["深度学习", "推理"],
  "actions": ["deploy", "train"]
}
```
