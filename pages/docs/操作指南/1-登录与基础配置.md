# 1. 登录与基础配置

首次使用 MLP Cooker 平台，您需要进行登录以及一些基础资源凭据配置。本指南将指导您完成平台的初始设置，以便顺利使用后续的各类管理功能。

## 平台登录

MLP Cooker 出于安全与多租户管理的需要，采用百度云 **Access Key (AK)** 和 **Secret Key (SK)** 进行身份认证。

### 登录步骤
1. 打开您的浏览器，访问 MLP Cooker 平台的 URL 地址。
2. 页面会自动跳转至登录窗口。
3. 在对应的输入框中填写您或您的项目管理员分配的百度云 **Access Key** 与 **Secret Key**。
4. 确认无误后点击“登录”，认证成功后系统会为您自动分配进入主控制台（概览页）。
   > **注意**：您的登录凭据将安全保存在后端服务配置中。在您后续的每一步操作中，系统都会默认采用这组认证信息下发任务。

## 凭证与租户管理

为了支持企业级环境中的多项目协作与资源隔离隔离，MLP Cooker 内置了多租户凭借管理系统。所有的云资源（如部署服务、训练集、模型等）默认都**按 AK/SK 相互隔离**。

### 多凭证自动隔离
1. **自动隔离策略**：系统完全基于您本次登录时使用的 AK/SK 凭证进行隔离。
2. **无需操作**：一旦使用不同的 AK/SK 成功登录，系统会自动筛选并只展示该凭证下辖的所有云端资源（如部署服务、训练集、模型等）。
3. **切换机制**：如果需要进入“数据组”或“算法组”互不干扰的项目环境，操作人员只需在登录页面输入为其专设的分配凭证登录即可，彻底做到了各组开销账单与运行资源严格分离，且不需要进任何“属性系统”做手动切换操作。

## 资源池与存储映射

每个独立项目需要关联具体的云端资源池和存储命名空间才可以调度任务。推荐在 **「全局配置」** 完成默认资源项配置，在 **「系统设置」** 维护 AK/SK 与区域等系统参数。

### 全局配置（推荐）

*   **默认资源池 / 默认队列**：新建训练、部署等任务时自动使用
*   **对象存储桶 / PFS 实例 ID**：数据集与存储浏览依赖
*   **平台组件**：可初始化或卸载 `mlp-cooker`（PFS 文件浏览依赖该组件）

### 系统设置

*   **Access Key / Secret Key**、区域、Base URL 等登录与 API 访问相关配置

配置完成后，各业务模块在新建表单中会**自动预填**上述全局配置。
