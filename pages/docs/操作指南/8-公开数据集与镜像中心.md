# 8. 公开数据集与镜像中心

在机器学习领域，“不要重复造轮子” 是提升效能的关键。MLP Cooker 内置了 **公开数据集 (Public Dataset)** 与 **镜像管理 (Image)** 模块，为您准备好了大量开箱即用、预先优化过滤的基础生产资料。

## 公开数据集一键化 (Public Datasets)

除开组织内部私有上传维护的数据集，平台还接入或转存了部分当前业界广泛使用的开源数据集或学术界标准评估测评库（如 ImageNet 抽取版，WMT，各种通用语言理解评估大满贯数据等）。

### 1. 查找与检索
* 在导航进入 **「公开数据集」** 模块。
* 平台分类展示了诸如自然语言处理、计算机视觉、时间序列分析等子领域流行的数据集。

### 2. Fork 取用与下载 
由于公开数据是所有人只读的数据池：
*   **私有化取用**：您可以点击“克隆/引入”，平台会自动完成一次高速云端互传（比您用自己网线下载快成百上千倍），将其搬运为您自己名下的独立私有 Dataset 副本，随后您就可以肆意在副本里做数据打标及预处理清洗了。
*   **公开数据集下载**：特定场景下，若您打算将验证集快速从公开版里抽拉一份到您挂载的本地开发机，这里也直接提供高速转运下载链接支持。

## 镜像库管理 (Image Center)

一切云原生任务的启动都依赖一个坚实可靠的基础环境。在 **「镜像管理」** 板块，您可以实现对镜像资产的查询甄别：

### 1. 预置镜像一览
如果您只是想要跑通一套比较标准的架构，您完全无需自己写 Dockerfile 慢慢构建打底包。系统在此展示了一系列深度优化的**底座公共环境**：
* 包含主流的不同 Pytorch / Tensorflow / Paddle 及其匹配良好绝不冲突的相应版本的 CUDA，CUDNN 配套驱动库。
* 提供对大模型加速类（如 vLLM / TGI 等热门推导算子）预装好相关编译产物的开箱即用大模型运行时。

### 2. 镜像信息详情
对于自上传和内部分发的任何镜像：
* 点击进入“详情”，能够看到它的**大小拉取体积**与**精确版本 Tag**。
* 您在 **「开发机」**、**「在线部署服务」** 或 **「模型训练发起」** 等动作中需要选择容器底层镜像时，其数据源全部来自于该列表。当团队有了新架构底层迭代时，只需维护该镜像中心即可一键分发给所有跑任务的小伙伴。
