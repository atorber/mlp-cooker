# 7. 开发机 (DevMachine) 使用指南

在正式提交大规模集群训练任务或者发布线上推理服务之前，算法工程师往往需要一个可以直接接入的云端调试环境来跑通 Baseline、测试算子、或进行数据可视化的 Exploratory Data Analysis (EDA)。

MLP Cooker 提供了开箱即用的 **「开发机 (DevMachine)」** 模块，为您提供专属的云上工作台。

## 创建云端开发机

进入左侧导航栏的 **「开发机」** 模块，点击“新建开发机”：
1. **基础环境选取**：与「新建部署」和「新建训练」类似，您可以为您要开辟的这台开发机挂载专属的镜像版本（包括常用的 PyTorch / TensorFlow 官方容器或者是带有特定 CUDA 驱动的环境等）。
2. **算力选型**：如果您仅仅是做做简单的文本规整化或爬虫，可以选择轻量级的 CPU 节点。如果您需要调试张量内存或是初步微调，请直接挂载一块或多块 NPU / GPU。
3. **数据挂载集成**：强烈建议您在创建开发机时，将自己的 PFS 或 BOS 存储卷同时挂载上去。这样在开发机里处理好的代码或中间产物将不会随着开发机销毁而丢失。

## 连接与调试体验

待开发机实例启动转入 `Running` 状态后，你可以通过以下方式接入您的云端环境进行编码与调试：

### 1. Web Terminal（浏览器原生终端）
* 平台可直接在当前网页中弹窗模拟终端命令行，这免除了您本地找私钥或者配置 SSH 隧道的痛苦。
* 可用来紧急查看挂载目录里的数据完整性，或是执行类似于 `top` 与 `nvidia-smi` 这种实时系统资源探查命令。

### 2. 深度绑定云端集成开发环境 (Web IDE)
* **JupyterLab**：对做数据清洗及探索的同学尤其友好。通过平台的端口穿透能力，点击对应按钮即可在新的浏览器标签页安全打开属于你的 Jupyter 网页实例，在线绘制 Matplotlib 图表。
* **SSH 级开发联调**：通常开发机也会暴露标准的 SSH Endpoint，你可以将此端点填入您本机的 VSCode Remote-SSH 插件中，实现无缝云端编码。

## 生命周期与成本提醒

由于开发机本质上等同于“买断”对应时长的算力卡，**即使您的代码并不在运行，您独占的算力计费可能仍在进行**。
> **💡 最佳实践**：
> 在每天下班或完成调试后，请务必返回「开发机」列表面板，将处于空闲的开发机 **「停止」** 甚至 **「删除」**（前提是资产已被转移至挂载并持久化的对象存储库里）。将机器释放进可用资源池，可以避免不必要的高昂闲置账单并让其他排队受阻的任务得以发车。
