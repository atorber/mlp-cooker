# 3. 在线服务部署指南

对于需要承接实时 HTTP/RPC 流量的在线模型算法服务，您可以在 **「部署」** 模块中进行服务实例的全生命周期托管。

## 在线查询服务

点击导航栏 **「部署」** 进入服务主列表：
*   **列表概览**：此处展示了所有历史与当前运行状态下的部署服务组。您可以直观看到其名称、状态、最新创建时间。
*   **状态指示灯**：系统提供了直观的标签指示服务当前的存活状态（如 _运行中_、_正在启动_、_失败_ 等）。
*   **辅助过滤**：您可以在顶部直接通过“队列”、“模糊服务名称”精确锁定服务位置。由于配置了租户隔离机制，您看到的将严格限定为您当前凭证下的资源。

## 新建与发布服务

除了[应用中心](2-应用模板使用指南.md)的一键快速部署外，您也可在此处手动发启部署：
1. 点击页面右上角的 **「新增部署」** 按钮。
2. 填选对应的在线服务表单。
3. **配置参数** 包括：
   * 选择您需要拉取与承载的模型和代码镜像；
   * 指定计算节点实例的资源要求（如选用何种类型的加速卡）；
   * 指明该服务暴露的端口和需要的环境变量。
4. 点击确认。此时 AIHC 平台便会在服务端拉起集群机器、下载代码数据并启动应用程序。

## 管理部署实例与日志检索

在服务的操作列点击详情：
*   **生命周期管理**：若需要关闭业务或者释放底层实例，您可直接操作“停止”或“删除”服务生命流。
*   **实例监控与排错**：每个部署可能包含多个子实例。您可以在详情页点击进入指定的 Pod，查询相关实例标准输出（STDOUT/ERR）的滚动日志，用于诊断报错或验证接口启动。
*   **副本与端点**：当服务启动完成后，其内部与外部 Endpoint 会列在详情里供其它业务发起请求连通调试。
