# 2. 应用模板使用指南

**应用中心** 是 MLP Cooker 平台的核心亮点之一。它提供了大量“开箱即用”的最佳实践模板，使得不熟悉深层云端底层 API 的用户也可以一键启动复杂的推导服务、微调训练流或数据处理流水线。

## 浏览与筛选应用

在左侧导航栏选择 **「应用」** 即可进入应用模板大厅：

1. **类别与标签**：每个模板卡片会使用徽章（Badge）标记它的应用场景（例如：`LLM`、`VLM` 等）。您可以通过页面左侧或顶部的快捷过滤器针对特定的业务分类精准缩减范围。
2. **文本搜索**：页面右上方提供了即时的高亮文本搜索框，根据模板名称或它描述的关键词可以快速定位。
3. **环境切换**：页面右上角包含**「灰度环境 / 生产环境」**切换开关。这保证了在应用大面积全员上线前，可以以“灰度发布”的方式进行试点和验证。
   * **灰度环境** 中通常包含着一些标有 `NEW` 的最新实验性应用。

## 查看应用详情与动作流

点击您感兴的任意一张应用模板卡片：
系统即会展开此应用的专属详细页面。在这里不仅可以看到详细的应用元数据，还能看到系统基于该模板封装好的所有 **执行动作 (Actions)** 按钮，常见的包括：
* **去部署 (Deploy)**：一键启动该应用作为一个在线推理 API 服务。
* **去训练 (Train)**：针对所选模型开始进行 LoRA 或全量微调训练。
* **创建任务 (Create Job)**：触发一次性执行的批量数据计算作业。

## 一键运行您的模板

当您点击上述执行按钮后，平台不会再要求您填写复杂的 YAML 定义，而是通过该模板：
1. **自动渲染弹窗表单**：模板里包含的所有基础资源引用均会被自动填充（如镜像地址、资源队列 ID 等）。
2. **轻量级自定义**：您只须在这个生成的表单里按需更改业务专属的变量参数（如启动实例个数、使用哪套个性化微调后的数据集等等）。
3. **确认提交**：点击确认后，MLP Cooker 的后端工作流引擎会自动编排好对应 `Deploy` 或 `Train` 资源的声明并提交到 AIHC 平台。随即您的任务便成功被启动。
