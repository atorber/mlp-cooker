# 2. 应用与模板使用指南

「应用」是一键启动入口，「模板」是配置资产库。应用通过 `templateId` 引用模板中的 `template_content`，避免在应用目录内重复维护任务参数。

## 应用：浏览与一键执行

左侧导航选择 **「应用」**：

![应用页](/img/screenshots/application.png)

1. **分类筛选**：模型 / 任务 / 工具
2. **关键词搜索**：按名称或描述过滤
3. **操作按钮**：部署、训练、创建任务等（取决于应用配置的 `actions`）

点击卡片可打开详情，查看：

- 应用元数据（类型、分类、标签）
- **关联模板**（模板 ID、模板名称）
- 解析后的配置参数（`taskParams`、启动命令、加速卡）

### 一键运行

1. 点击操作按钮，弹出参数表单（默认值来自关联模板）
2. 按需修改环境变量等业务字段
3. 确认后提交到 AIHC（训练 / 部署 / 批量任务）

### 从训练任务导入

1. 点击「导入训练任务」
2. 选择已有训练任务
3. 系统会自动创建模板（保存配置）并创建应用（写入 `templateId`）

## 模板：管理配置资产

左侧导航 **「AI资产」→「模板」**：

![模板页](/img/screenshots/template.png)

1. **来源 Tab**：全部 / 预置 / 自定义
2. **筛选**：功能模块、标签、关键词
3. **新增自定义模板**：填写名称、图标、简介、文档地址、模块、子模块、标签与模板内容
4. **详情**：可查看文档预览（Markdown）与 `template_content`（YAML/JSON 或外链）

### 功能模块与子模块联动

选择「所属功能模块」后，子模块下拉只展示该模块下的选项。例如：

- 选择「工作流」→ 可选「工作流模板」「子任务模板」
- 选择「分布式训练」→ 可选「任务模板」

### 预置与自定义

- **预置模板**：平台内置，只读
- **自定义模板**：可编辑、删除；适合沉淀个人或团队配置

## 应用与模板如何配合

典型流程：

1. 在「模板」中维护一份训练/部署配置（`template_content`）
2. 在「应用」中创建入口，动作为该模板的 `templateId`
3. 用户在应用页一键执行，无需关心底层 JSON 细节

这样配置集中在模板库，应用页保持轻量、可执行。
