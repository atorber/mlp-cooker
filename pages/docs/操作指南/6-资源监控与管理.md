# 6. 资源与监控看板

当涉及多人员使用相同预算云端配额时，掌握实时的资源争抢状况、排队长度与使用健康情况（GPU/CPU）是至关重要的。为此，MLP Cooker 为用户打造了多维的盘点面板。

## 控制台统计概览

登录后的首页 **「控制台概览 (Welcome)」** 即为系统运行总体态势图：
*   **宏观数量：** 分别统计当前该 AK/SK 视角下拥有的所有正在活跃维护着的：部署数、训练任务数、批量执行任务以及现存注册的数据集及模型数。
*   **资源大满贯盘点：** 在这块您可以直截了当地看到自己租户在当前所有可用算力资源池（计算队列）上的瞬时状况，例如在跑的任务是不是快顶占满分配了的卡点阈值。

## 详细计算资源查询

如果遇到“我发起了训练但一直提示资源不足无法排队上车”等现象时，您需要前往左侧 **「计算资源 (Resource)」**，进行下钻排查：

### 1. 队列信息监控
*   显示当前绑定在您环境下的各个专享与共享队列。
*   如果队列本身设定了最高 Quota 抢占限制或者正在遭受高拥堵，您能够查阅到有多少任务正处于“Pending（阻塞排队）”等待中。

### 2. 加速卡及 CPU/内存情况
*   **多维度硬件健康度：** 除却普通的 CPU / Memory 使用率波峰曲线查看。
*   **AI 加速卡专门监控：** 您可以直观获取被切分占用的 NPU / GPU 空闲卡槽位。对于 AIHC 特定的分布式模型部署来说，这为您评估未来 24 小里是否有闲置容灾节点跑“非核心探索任务”提供了极大便利与决策参考点。
