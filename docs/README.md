# MLP Cooker 产品官网

**一站式机器学习平台管理系统** — 基于 Node.js + TypeScript + React 的现代化 AIHC 平台资源管理工具，覆盖部署、训练、任务、数据集、模型等全生命周期管理。

---

## 产品定位

MLP Cooker 面向使用百度百舸 AIHC 平台的团队与开发者，提供：

- **统一控制台**：在一个界面中管理推理服务、训练任务、批量任务、数据集与模型
- **应用模板**：预置部署/训练/任务模板，支持一键部署与快速创建
- **资源可视**：队列、资源池、加速卡与 CPU/内存使用一目了然
- **配置集中**：YAML 配置与 AK/SK 认证，便于本地或内网部署

适用于算法工程师、运维与平台管理员，提升在 AIHC 上的日常操作效率。

## 快速体验

- **Mac 用户**：一键安装并启动后端  
  `curl -fsSL https://raw.githubusercontent.com/atorber/mlp-cooker/main/install-mac.sh | bash`
- **手动安装**：参见 [快速开始](./快速开始.md) 或项目根目录 [README.md](../README.md)、[INSTALL.md](../INSTALL.md)。

开发环境默认访问：前端 http://localhost:8000 ，后端 API http://localhost:8001 。登录使用 AIHC 的 Access Key / Secret Key。
