# 快速开始

本文档帮助你在本地或内网快速安装、配置并运行 MLP Cooker。

## 环境要求

- **Node.js** >= 20.0.0  
- **npm** >= 8.0.0  

（Mac 用户使用一键脚本时，脚本会检查并引导安装 Homebrew、Git、Node.js。）

---

## 方式一：Mac 一键安装（推荐）

在 macOS 上可直接使用项目提供的安装脚本：

```bash
curl -fsSL https://raw.githubusercontent.com/atorber/mlp-cooker/main/install-mac.sh | bash
```

若已克隆仓库：

```bash
cd mlp-cooker
./install-mac.sh
```

脚本会完成环境检查、依赖安装并启动后端。更多说明见项目根目录 [INSTALL.md](../INSTALL.md)。

---

## 方式二：手动安装

### 1. 克隆项目

```bash
git clone https://github.com/atorber/mlp-cooker.git
cd mlp-cooker
```

### 2. 安装依赖

**后端：**

```bash
cd backend
npm install
```

**前端：**

```bash
cd frontend
npm install
```

### 3. 配置平台信息

在**项目根目录**创建 `config.yaml`，填入你的 AIHC 平台信息（可从百度云控制台获取）：

```yaml
ML_PLATFORM_RESOURCE_AK: your_access_key
ML_PLATFORM_RESOURCE_SK: your_secret_key
ML_PLATFORM_RESOURCE_BASE_URL: https://aihc.bj.baidubce.com
ML_PLATFORM_RESOURCE_POOL_ID: your_resource_pool_id
ML_PLATFORM_RESOURCE_QUEUE_ID: your_queue_id
ML_PLATFORM_RESOURCE_PFS_INSTANCE_ID: your_pfs_instance_id
ML_PLATFORM_RESOURCE_BUCKET: your_bucket_name
```

也可在首次通过前端「系统设置」登录（使用 AK/SK）后，由系统写入 `config.yaml`。

### 4. 启动服务

**开发环境（推荐）：**

- 终端 1 — 后端：`cd backend && npm run dev`（默认 http://localhost:8001）
- 终端 2 — 前端：`cd frontend && npm run start:dev`（默认 http://localhost:8000）

**生产构建：**

- 前端：`cd frontend && npm run build`
- 后端：`cd backend && npm run build && npm run start:prod`

---

## 访问与登录

- **前端**：浏览器打开 http://localhost:8000  
- **后端 API**：http://localhost:8001  

登录使用 AIHC 的 **Access Key (AK)** 和 **Secret Key (SK)**。首次登录成功后，系统会将 AK/SK 写入 `config.yaml`，后续请求将使用该配置。
