操作指南

本章节提供 MLP Cooker 平台各核心模块的最终用户使用指南。

📄️ 1. 登录与基础配置

首次使用 MLP Cooker 平台，您需要进行登录以及一些基础资源凭据配置。本指南将指导您完成平台的初始设置，以便顺利使用后续的各类管理功能。

📄️ 2. 应用与模板使用指南

「应用」是一键启动入口，「模板」是配置资产库。应用通过 templateId 引用模板中的 template_content，避免在应用目录内重复维护任务参数。

📄️ 3. 在线服务部署指南

对于需要承接实时 HTTP/RPC 流量的在线模型算法服务，您可以在 「部署」 模块中进行服务实例的全生命周期托管。

📄️ 4. 训练与任务管理指南

在大中型模型微调及海量数据批处理场景下，使用 MLP Cooker 的 训练 (Training) 和 任务 (Task) 管理模块能有效调度平台算力资源，并进行多卡及多机网络并行训练。

📄️ 5. 数据与模型资产管理

算法团队的产出与血液永远是数据及算法成果。在 MLP Cooker 中，数据集、模型、镜像、任务统一归入左侧导航 「AI资产」；文件级浏览（存储桶 / PFS）请前往 「资源 → 存储」。

📄️ 6. 资源与存储管理

资源菜单组统一管理算力与存储浏览能力，路径前缀为 /resource。

📄️ 7. 开发机 (DevMachine) 使用指南

在正式提交大规模集群训练任务或者发布线上推理服务之前，算法工程师往往需要一个可以直接接入的云端调试环境来跑通 Baseline、测试算子、或进行数据可视化的 Exploratory Data Analysis (EDA)。

📄️ 8. 公开数据集与镜像中心

在机器学习领域，“不要重复造轮子” 是提升效能的关键。MLP Cooker 内置了 公开数据集 (Public Dataset) 与 镜像管理 (Image) 模块，为您准备好了大量开箱即用、预先优化过滤的基础生产资料。

📄️ 9. 工作流 (Workflow) 管理指南

对于大型且复杂的人工智能应用，单纯跑一发任务或者单纯发个在线服务早已无法满足需求。真实的工业场景通常包含一串承上启下的流水线（Pipeline）。
