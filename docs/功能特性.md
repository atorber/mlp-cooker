# 功能特性

## 概览

MLP Cooker 围绕 AIHC 平台的核心资源与操作，提供以下功能模块：

| 模块 | 能力简述 |
|------|----------|
| 概览 | 平台统计与资源使用总览 |
| 应用 | 应用模板库，一键部署/训练/任务 |
| 部署 | 推理服务的创建、查询、删除与状态监控 |
| 训练 | 训练任务的创建、查询、停止与删除 |
| 任务 | 批量任务列表与详情（如 task-* 任务） |
| 数据集 | 数据集与版本管理，支持 BOS、PFS |
| 模型 | 模型与版本管理 |
| 镜像 | 预置镜像查询与管理 |
| 计算资源 | 队列、资源池、加速卡与 CPU/内存监控 |
| 系统设置 | 平台配置、AK/SK、资源池/队列等 |

---

## 核心模块说明

### 部署管理

- 服务列表查询（支持按队列、关键词筛选）
- 服务详情与状态查看
- 基于模板或自定义配置创建服务
- 删除服务

适用于日常推理服务上线、扩缩容与下线。

### 训练管理

- 训练任务列表与详情
- 创建训练任务（含分布式）
- 停止、删除任务

与应用模板结合可快速从模板创建标准训练任务。

### 任务管理

- 批量任务列表（如自动筛选以「task-」开头的任务）
- 任务详情查看

便于统一查看与追踪批量任务。

### 数据集管理

- 数据集列表（支持 BOS、PFS 类型筛选）
- 数据集详情与版本
- 创建数据集与版本、删除数据集/版本

方便在控制台内完成数据准备与版本管理。

### 模型管理

- 模型列表与详情
- 创建模型与版本、删除模型/版本

与部署、训练流程衔接，形成「数据 → 训练 → 模型 → 部署」的闭环。

### 应用模板

- 预置部署、训练、任务、工具等模板
- 每个应用包含元数据（`app.json`）与操作模板（如 `deploy.json`、`train.json`）
- 支持一键部署推理、创建训练与任务

详见仓库内 [应用模板开发文档](../backend/data/app/README.md)。

### 计算资源

- 队列信息与详情
- 资源池信息
- 加速卡、CPU、内存使用情况

便于做容量规划与成本观测。

### 系统设置

- 查看与编辑平台相关配置（如 Base URL、资源池 ID、队列 ID、PFS、Bucket 等）
- AK/SK 配置（支持显示/隐藏）
- 配置持久化到本地 `config.yaml`

## 技术特性摘要

- **前端**：React 19、TypeScript、Ant Design Pro、Umi 4、ProComponents；响应式布局；支持中英文。
- **后端**：Node.js、Express、TypeScript；RESTful API；YAML 配置；百度云 SDK；AK/SK 认证；CORS、统一错误处理与日志。

更细的技术栈说明见 [技术栈](./技术栈.md)。
