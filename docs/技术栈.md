# 技术栈

## 总体架构

MLP Cooker 采用前后端分离架构：前端负责界面与交互，后端负责与 AIHC 平台 API 通信及配置管理。

---

## 后端

| 类别 | 技术 |
|------|------|
| 运行时 | Node.js 20+ |
| 框架 | Express 5 |
| 语言 | TypeScript 5 |
| 配置 | js-yaml（YAML 配置管理） |
| 平台对接 | @atorber/baiducloud-sdk（百度云 / AIHC） |

**特性摘要**：RESTful API、基于 AK/SK 的认证中间件、CORS 支持、统一错误处理与日志、配置持久化到 `config.yaml`。

---

## 前端

| 类别 | 技术 |
|------|------|
| 框架 | React 19 |
| 语言 | TypeScript 5 |
| UI | Ant Design 5、ProComponents |
| 应用框架 | Umi 4 (Max) |
| 代码规范 | @biomejs/biome（格式化等） |

**特性摘要**：响应式布局、开发热重载、中英文国际化、与后端 RESTful API 对接。

---

## 端口与配置

- 后端默认端口：**8001**（可在配置中修改）  
- 前端开发默认端口：**8000**  
- 平台相关配置（AK/SK、Base URL、资源池/队列/PFS/Bucket 等）集中在项目根目录 **config.yaml**，也可通过前端「系统设置」编辑。
