开发指南

本章节提供 MLP Cooker 的开发指南,帮助您快速上手开发。

快速开始​

🚀 Mac 用户一键安装（推荐）​

如果您使用的是 macOS 系统，可以使用我们提供的自动化安装脚本：

方式一：直接运行（推荐）​

以下命令可以一键安装运行环境、下载代码、安装依赖，小白用户强烈推荐~

curl -fsSL https://raw.githubusercontent.com/atorber/mlp-cooker/main/install-mac.sh | bash

方式二：先克隆再运行​

熟悉git的用户可以先自行clone，再安装依赖和运行

git clone https://github.com/atorber/mlp-cooker.git
cd mlp-cooker
./install-mac.sh

安装脚本功能​

安装脚本会自动完成以下步骤：

  1. ✅ 检查系统环境 - 确认是否为 macOS 系统
  2. ✅ 安装 Homebrew - Mac 的包管理器（如果未安装）
  3. ✅ 安装 Git - 版本控制工具（如果未安装）
  4. ✅ 安装 Node.js - JavaScript 运行环境（版本 >= 20.0.0）
  5. ✅ 克隆项目代码 - 从 GitHub 获取最新代码
  6. ✅ 安装项目依赖 - 自动安装后端和前端的所有 npm 包
  7. ✅ 构建项目 - 编译 TypeScript 代码

💡 注意：安装脚本只负责安装和构建，不会自动启动服务。安装完成后，请使用启动脚本启动服务。

🎯 启动服务​

环境、代码、依赖安装完成后，使用以下方式启动服务：

方式一：使用启动脚本（推荐）​

cd mlp-cooker
./start.sh

启动脚本会：

  • 同时启动前端和后端服务
  • 在后台运行，输出日志到文件
  • 支持 Ctrl+C 优雅停止所有服务

方式二：手动启动​

需要在两个终端分别启动：

终端 1：启动后端

cd backend
npm run dev

终端 2：启动前端

cd frontend
npm run start:dev

🌐 访问服务​

启动成功后，可以通过以下地址访问：

  • 后端 API: http://localhost:5002 (或 http://0.0.0.0:5002)
  • 前端应用: http://localhost:8000

📋 查看日志​

如果使用启动脚本，日志文件保存在 logs/ 目录：

# 查看后端日志
tail -f logs/backend.log

# 查看前端日志
tail -f logs/frontend.log

开发环境配置​

环境要求​

  • Node.js: >= 20.0.0
  • npm: >= 8.0.0
  • 操作系统: macOS (其他系统请参考手动安装步骤)

配置文件​

在项目根目录创建 config.yaml 文件，配置机器学习平台资源信息：

ML_PLATFORM_RESOURCE_AK: your_access_key
ML_PLATFORM_RESOURCE_SK: your_secret_key
ML_PLATFORM_RESOURCE_BASE_URL: https://aihc.bj.baidubce.com
ML_PLATFORM_RESOURCE_POOL_ID: your_resource_pool_id
ML_PLATFORM_RESOURCE_QUEUE_ID: your_queue_id
ML_PLATFORM_RESOURCE_PFS_INSTANCE_ID: your_pfs_instance_id
ML_PLATFORM_RESOURCE_BUCKET: your_bucket_name

如果不创建配置文件，服务会在默认配置下运行（某些功能可能不可用）。

常用开发命令​

后端开发​

cd backend

# 开发模式（热重载）
npm run dev

# 构建项目
npm run build

# 生产模式启动
npm start

# 代码检查
npm run lint

# 自动修复代码格式
npm run lint:fix

# 代码格式化
npm run format

前端开发​

cd frontend

# 开发模式启动
npm run start:dev

# 构建生产版本
npm run build

# 预览生产构建
npm run preview

# 代码检查
npm run lint

# 运行测试
npm test

开发流程​

添加新页面​

  1. 在 frontend/src/pages/ 中创建新的 React 组件
  2. 在 frontend/config/routes.ts 中添加路由配置
  3. 在 frontend/src/locales/zh-CN/menu.ts 和 frontend/src/locales/en-US/menu.ts 中添加菜单项

添加新 API​

  1. 在 backend/src/controllers/ 中创建新的控制器
  2. 在 backend/src/routes/index.ts 中添加路由
  3. 在 frontend/src/services/aihc-mentor/api.ts 中添加 API 调用函数
  4. 在相应的 React 组件中调用 API

样式开发​

  • 全局样式: frontend/src/global.less
  • 组件样式: 每个组件对应的 .less 文件
  • UI框架: Ant Design + ProComponents

目录结构​

.
├── backend/                  # 后端应用
│   ├── src/                  # TypeScript 源代码
│   │   ├── app.ts           # Express 应用入口
│   │   ├── controllers/     # 控制器
│   │   ├── middleware/      # 中间件
│   │   ├── routes/          # 路由定义
│   │   └── utils/           # 工具函数
│   └── data/                # 数据文件
├── frontend/                # 前端应用
│   ├── src/                 # React 源代码
│   │   ├── pages/           # 页面组件
│   │   ├── components/      # React 组件
│   │   └── services/        # API 服务
│   └── config/              # 前端配置
└── config.yaml              # 系统配置文件
