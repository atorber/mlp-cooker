# 产品介绍

## 背景与目标

企业在使用百度百舸 AIHC 平台时，往往需要在控制台、API 与本地脚本之间频繁切换，完成服务部署、训练任务创建、数据集与模型管理等操作。流程分散、重复操作多，不利于团队协作与效率提升。

**MLP Cooker** 的目标是：为 AIHC 平台提供**一站式管理控制台**，把部署、训练、任务、数据集、模型、镜像与计算资源整合到同一套界面与工作流中，并支持通过应用模板实现一键部署与标准化流程。

## 产品价值

- **提效**：统一入口完成日常运维与资源管理，减少在多处控制台间的切换。
- **标准化**：通过应用模板固化最佳实践，新人也可快速完成部署与训练创建。
- **可观测**：集中查看队列、资源池、加速卡与 CPU/内存使用，便于容量与成本管理。
- **可落地**：支持本地或内网部署，配置与认证（AK/SK）集中管理，便于与现有流程集成。

## 系统架构概览

MLP Cooker 采用**前后端分离**架构：

- **后端**：Node.js + Express + TypeScript，对接百度云 SDK（`@atorber/baiducloud-sdk`），提供 RESTful API；配置通过 YAML（如 `config.yaml`）统一管理。
- **前端**：React 19 + TypeScript + Ant Design Pro（Umi 4），提供控制台 UI、应用模板入口与资源看板。
- **认证**：基于 AK/SK 的认证机制，登录后可将凭证写入配置文件，便于后续请求。

整体上，前端负责展示与交互，后端负责与 AIHC 平台 API 通信及配置持久化，适合作为团队内网或本地的“AIHC 管理门户”。

## 适用对象

- **算法/研发**：日常发起训练、创建任务、管理数据集与模型。
- **运维/平台**：部署推理服务、管理队列与资源池、监控资源使用。
- **团队负责人**：通过统一控制台与模板规范团队使用方式，提升协作效率。

## 与 AIHC 的关系

MLP Cooker 是运行在您本机或内网中的**管理客户端**，不替代 AIHC 平台本身，而是：

- 调用 AIHC 开放 API 完成各类操作；
- 在本地/内网保存配置（如 AK/SK、资源池 ID、队列 ID 等）；
- 通过应用模板与脚本扩展，封装您团队的常用流程。

数据与算力仍在 AIHC 平台侧，MLP Cooker 仅做编排、展示与配置管理。
